# Shelf

A small public registry of Chromium extensions for [Helium](https://helium.computer) and ungoogled-chromium. One-click install, automatic updates, and authors keep their own signing keys.

**Browse:** [shelf.niduslabs.dev](https://shelf.niduslabs.dev). Installing needs one Helium setting, which the site walks you through.

**List an extension:** start from the [template repo](https://github.com/niduslabs-dev/shelf-extension-template). Its Action packs and signs your release and gives you the pull request to open here. Read [how Shelf reviews extensions](REVIEW.md) first.

**Report a problem:** [open an issue](https://github.com/niduslabs-dev/shelf/issues/new/choose). Malware or a leaked key: see [SECURITY.md](SECURITY.md), and report it privately.
